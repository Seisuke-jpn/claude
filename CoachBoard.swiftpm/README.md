# CoachBoard（試作版 0.1）

動画を再生しながら Apple Pencil で書き込み、その様子を声と一緒に録画できる iPad アプリです。
VALORANT のクリップ解説や、雑談しながらのメモ書きを想定しています。

## この試作でできること

| 機能 | 内容 |
|---|---|
| 動画を開く | 写真ライブラリ／ファイルアプリから |
| 再生 | 再生・停止、1コマ送り・戻し、シークバー、0.25〜2倍速 |
| 描画 | Apple Pencil で手描き（6色・3段階の太さ）、戻す、全消去 |
| 描画オプション | 「指で描く」（オフなら Pencil だけ反応＝手のひらが当たっても平気）、「再生で消す」（再生を押すと線を消す） |
| 録画 | 動画＋手描き＋マイク音声を 30fps で録画。**動画を止めている間も録画は続き、止めた画面に描いた様子も録画される** |
| メモボード | 動画を開かなくても、黒板として描いて録画できる（雑談メモ用） |
| 保存 | 録画一覧から 再生／写真に保存／共有・ファイルに保存／削除（左スワイプ） |

## iPad への入れ方（Swift Playgrounds）

1. App Store から **Swift Playgrounds**（無料）をインストール
2. iPad の Safari で GitHub のこのブランチを開き、「Code」→「Download ZIP」でダウンロード
3. ファイルアプリでダウンロードした ZIP をタップして展開
4. 中にある **`CoachBoard.swiftpm`** をタップ → Swift Playgrounds で開く
5. 右上の ▶︎（実行）を押すとアプリが起動
6. 初回の録画時にマイクの許可、初回の写真保存時に写真の許可を求められるので「許可」

> 全画面で試すときは、Swift Playgrounds の実行画面右上のボタンから全画面表示にしてください。

## 使い方

1. 「動画を開く」で VALORANT のクリップを選ぶ（開かなければメモボードになる）
2. 「録画開始」
3. 再生しながら解説 → 止めて Pencil で書き込む → 再生（「再生で消す」がオンなら線が消える）
4. 「録画停止」→ 録画一覧が開くので、そこから写真に保存／共有

## 試作版の制限（次の段階で対応予定）

- **ゲームの音は「スピーカーから出た音をマイクが拾う」形で入る**。イヤホン使用時はゲーム音が録画に入らない
  → 次の段階で、動画の音を直接録画に混ぜる処理を追加予定
- 録画は 1080p / 30fps 固定
- カット編集、矢印・図形ツール、消しゴム（線単位）は未実装
- 録画中は別の動画を開けない

## ファイル構成

```
CoachBoard.swiftpm/
├─ Package.swift            アプリ設定（権限・アイコンなど）
├─ CoachBoardApp.swift      起動
├─ Views/
│  ├─ ContentView.swift     メイン画面（上バー・ボード・再生バー）
│  ├─ ToolPalette.swift     右側のペン道具
│  └─ RecordingsView.swift  録画一覧・再生・保存
├─ Player/
│  ├─ PlayerController.swift 再生制御と録画用フレーム取り出し
│  ├─ PlayerSurface.swift    動画表示
│  └─ VideoImport.swift      写真／ファイルからの取り込み
├─ Ink/
│  ├─ InkModel.swift        線データ（正規化座標）
│  ├─ InkRendering.swift    線の描画・画像化
│  └─ InkCanvasView.swift   Pencil 入力
└─ Recording/
   ├─ SessionRecorder.swift 30fps で合成し続ける録画の司令塔
   ├─ MovieWriter.swift     mp4 への書き込み（映像＋マイク）
   └─ RecordingsStore.swift 録画ファイルの管理・写真への保存
```

## 仕組み（録画が止まらない理由）

画面をそのまま録画するのではなく、1秒に30回、
「動画の今のフレーム（止めていれば止めたフレーム）」＋「手描きの線」を合成して書き込んでいます。
動画の再生状態と録画は独立しているので、止めても録画は続きます。
